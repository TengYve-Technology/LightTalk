# LightTalk - 局域网聊天室

一个轻量级的局域网即时通讯应用，基于 Node.js + Express + SSE (Server-Sent Events) 实现实时通讯，无需数据库，开箱即用。

## ✨ 功能特性

- 💬 **实时聊天** - 基于 SSE 实现低延迟消息推送
- 🏠 **房间/频道** - 支持创建、加入、切换多个聊天房间
- 👥 **用户管理** - 注册、登录、在线状态显示、用户搜索
- 🔐 **认证授权** - JWT Token 认证，支持管理员权限
- 📁 **文件传输** - 支持图片、文件上传下载（最大 10MB）
- 🖼️ **图片预览** - 聊天中直接预览图片，支持模态框放大查看
- 🎨 **表情符号** - 内置表情选择器
- 💬 **消息回复** - 支持引用回复消息
- 🗑️ **消息管理** - 删除自己的消息，管理员可删除任意消息
- 👤 **个人设置** - 修改显示名称、密码、上传头像
- 📱 **响应式设计** - 适配桌面端和移动端

## 🚀 快速开始

### 环境要求

- Node.js 16+ 
- npm 或 yarn

### 安装依赖

`ash
cd lan-chat
npm install
`

### 启动服务

`ash
npm start
`

服务启动后，控制台会显示访问地址：

## 📖 使用指南

### 1. 首次登录 / 注册

1. 打开应用，默认显示登录/注册弹窗
2. **管理员首次登录**: 使用 admin / admin123 登录，**强烈建议登录后立即修改密码**
3. **普通用户**: 点击注册标签创建新账号

### 2. 界面布局

`
侧边栏                          主聊天区域
┌─────────────────────────┐    ┌─────────────────┐
│ 用户信息/头像           │    │ 房间名称/状态   │
├─────────────────────────┤    ├─────────────────┤
│ [房间] [用户] [设置]     │    │ 消息列表        │
├─────────────────────────┤    │                 │
│ 房间列表 / 用户列表      │    │                 │
└─────────────────────────┘    ├─────────────────┤
                               │ 输入框 [发送]   │
                               └─────────────────┘
`

### 3. 核心功能操作

#### 发送消息
- 在底部输入框输入文字，按 Enter 或点击发送按钮
- 支持 Shift+Enter 换行

#### 发送表情
- 点击输入框左侧的 😊 表情按钮打开表情选择器
- 点击表情即可插入到输入框

#### 发送文件/图片
- 点击 📎 附件按钮选择文件
- 支持图片（预览）、文档等文件类型
- 单文件最大 10MB

#### 回复消息
- 右键点击任意消息（或长按），选择回复
- 输入框上方显示回复预览，发送后自动关联原消息

#### 删除消息
- 右键点击自己的消息，选择删除
- 管理员可删除任意用户的消息

#### 切换房间
- 侧边栏房间标签下点击房间名称切换
- 点击 + 创建新房间（需输入房间名，可选描述）

#### 查看在线用户
- 侧边栏切换到用户标签
- 绿点表示在线，灰点表示离线
- 支持搜索用户

#### 个人设置
- 侧边栏切换到设置标签
- **修改显示名称**: 输入新名称点击保存
- **修改密码**: 输入当前密码和新密码（至少6位）
- **更换头像**: 点击更换头像上传图片
- **退出登录**: 点击红色的退出登录按钮

### 4. 管理员功能

使用 admin 账号登录后拥有：
- 删除任意用户的消息
- 查看所有用户状态
- 管理房间（后续版本支持）

## 🌐 网络部署建议

### 局域网内使用
1. 确保服务器和客户端在同一局域网
2. 服务器防火墙开放 3002 端口（或自定义端口）
3. 客户端使用服务器的局域网 IP 访问

### 跨网段/公网访问（生产环境建议）
- 使用 Nginx 反向代理 + HTTPS
- 配置域名和 SSL 证书
- 考虑使用 WebSocket 替代 SSE 以获得更好的兼容性
- 引入 Redis 实现多实例消息同步
- 接入数据库（PostgreSQL/MySQL）持久化数据

## ⚠️ 注意事项

1. **默认密码**: 首次部署请务必修改管理员默认密码 admin123
2. **数据持久化**: 当前版本使用内存存储，重启服务会丢失聊天记录和用户数据
3. **文件存储**: 上传文件存储在 public/uploads/ 目录，建议定期清理
4. **安全性**: 生产环境请启用 HTTPS，使用强密码策略
5. **并发限制**: 单进程 Node.js 适合中小规模（<500并发），大规模需集群化

`ash
npx nodemon src/server.js
`

### 查看日志
控制台会输出：
- 服务启动信息（本地/局域网地址）

- API 请求错误堆栈

### 常见问题

| 问题 | 解决方案 |
|------|----------|
| 端口被占用 | 修改 PORT 环境变量或关闭占用进程 |
| 局域网无法访问 | 检查防火墙，确保 3002 端口开放 |
| 文件上传失败 | 检查 public/uploads/ 目录写入权限 |
| 消息不实时 | 检查浏览器网络面板 SSE 连接状态 |
